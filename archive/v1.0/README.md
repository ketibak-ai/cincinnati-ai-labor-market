# Cincinnati AI Labor Market 1.0 — archived text

`report.txt` is a plain-text extraction of the 1.0 report as published in the Claude Doc at
claude.ai/artifact/RszZtyNchr44mfR2PeNqvZ (document revision 43), taken on 13 November 2026.
Tables are flattened to one cell per line, so table rows span several lines. The extraction
exists so that the 2.0 design memo and AUDIT.md can cite 1.0's wording by file and line.

The repository state that produced 1.0 is the git tag `v1.0` (commit d4a1d36). The 1.0 tests
are `tests/test_study.py` at that tag.

Nothing in this folder is edited. Corrections to 1.0 are recorded in `AUDIT.md`.
